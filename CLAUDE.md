# Новогодняя площадь

Игра отдела продаж на декабрь 2026: шесть групп наряжают общую ёлку за процент плана и украшают домики за счета 6+ и 20+.

## Где что
- Спека и план: `docs/superpowers/` (только локально, в git нет: там показатели групп).
- Карта кода: `NAVIGATOR.md`. Состояние между сессиями: `PLAN.md`. Выпуск: `docs/deploy.md`.

## Правила
- Интерфейс русский, идентификаторы английские. Игровые числа — в `src/engine/config.ts` и `catalog.ts`, цены после старта не меняем.
- Движок (`src/engine`) — чистые функции: без DOM, сети, часов. Сначала падающий тест.
- Сервер хранит факты. Засчитанная покупка не исчезает от правок, её убирает только отмена из админки.
- В репозитории нет ФИО, xlsx, PIN, адреса `/exec`, ключа экрана. Имена в тестах выдуманные. `git add` только явными путями.
- Пуш, деплой, `Code.gs`, запись в живую таблицу — после «да» владельца. PIN вводит только владелец.
- Последних мест не показываем. На персонажах нет свечения, только овал на земле.

## Команды
`npm run dev` · `npm test` · `npm run build` · `npm run audit:publish -- <xlsx…>` · `npm run guard`
